## 1. 交付物

### 1.1 模块 `apps/api/productdirector_api/publish_package.py`

| 能力 | 实现与诚实边界 |
| --- | --- |
| 包结构 | 按 12.7 生成 `manifest.json` + `video/{final,clean_master}` + `subtitles/<locale>.{srt,vtt}` + `audio/{voice,mixed}` + `images/thumbnail.jpg` + `copy/{caption,hashtags,product_facts}` + `metadata/{platform_profile,lineage,qa_report,rights_manifest,cost_summary}` + `publish/{request.template.json,README.md}`；**未启用的内容不出现在包里**（也绝不假称已生成） |
| Manifest | `schema_version`、package/version、project/product/plan/profile/run/batch、locale、video 规格、`files[]`（path/sha256/size/mime/role）、QA、approval_ref、rights_refs、字幕/配音/BGM 状态、warnings、created_at |
| 凭证检查 | `check_manifest_secrets`：禁止 API Key/token/cookie 字段、疑似凭证串、带签名的临时下载链接（构建时与验证时都查） |
| 许可清单 | `rights_manifest`：**音乐原文件默认不入包**（有权用 BGM 做成片 ≠ 有权单独分发音乐），只保留许可引用与混音记录；Profile 规则来源与核验状态如实记录 |
| 无凭证模板 | `publish_request_template`：只声明需要平台授权/有效审批/可见性确认，**不是可自动执行的脚本** |
| ZIP 安全 | `zip_package`：条目名防目录穿越、写后复核条目集合与 CRC、重新计算整包哈希 |
| 校验与审批 | `verify_package`（文件齐备、哈希一致、无未声明文件、Manifest 无凭证）+ `approve` 绑定 `content_hash`；审批后任何文件变化都会使审批失效（下载时再校验 ZIP 哈希） |
| 批次归档 | 只收集**已审批**的包，未审批内容不进入可发布归档 |

### 1.2 API

`POST /runs/{id}/packages`（build+verify）、`GET /packages`、`GET /packages/{id}`、`POST /packages/{id}/verify`、`POST /packages/{id}/approve`（content_hash 绑定）、`GET /packages/{id}/download`（下载前复核 ZIP 哈希）、`POST /batches/{id}/packages/archive` + 下载（聚合 ZIP）。新增表 `publish_packages`（内联 schema 与 `db/schema.postgres.sql` 同步）。

### 2.1 如实记录：本片**没有达到 brief 的产品保真要求**

- 重建来自**单视图**、**只有几何、没有贴图**：白色光泽外壳、黑色亮面罩、蓝紫镜头、顶部投影等细节与原参考图不一致；胸前喇叭被重建为平面圆盘。
- 产品在部分场景中**悬空**（接地阴影是**由遮罩模糊生成的程序化阴影**，不是渲染出的真实阴影层），且与背景透视未做三维匹配（无房间几何）。
- 配音为**离线 espeak 预览音色**（非商用发行音色）；**无 BGM**（没有授权音乐库，Manifest 标 disabled）。
- 因此该成片可以作为**真实链路样片/包结构验证**，**不能**作为正式投放素材；brief 明确要求「保持参考图的产品设计不变」，这一条未满足。
