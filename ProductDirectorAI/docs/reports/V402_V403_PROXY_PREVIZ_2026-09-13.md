接触 QA 语义（真实几何、主规划 V4 阈值）：
- 接触 = 手到锚点**表面**间隙 ≤ min(2cm, 锚点半径)，检查声明接触帧起的保持窗口；
- 实际接触帧 = 全片第一次进入阈值（与声明帧偏差 ≤2 帧）；
- 穿透 = 手部中心**严格进入产品包围盒体积**后的深度（到最近面距离）≤1cm 且 ≤2 帧。

## 2. 真实渲染证据（云端 Blender 5.2.1，540×960）

### 正例：CC0 相机顶盖 press_button（人物 1.7–1.8m，锚点 bbox (0.5,0.5,1.0)）

| 指标 | 结果 |
| --- | --- |

### 负例：官方产品顶部锚点 + 矮人物（0.9–1.0m，可达高 1.0925m < 锚点 1.45m）

- `contact_qa.passed = false`，**exit 1**：`穿透 0.0866m 超过 0.01m（帧 20–27）`——人物够不到顶部锚点，手沿路径真实穿入产品包围盒体积，被几何 QA 拦截（fail-closed 生效）。
- 该负例同时说明：可达带钳制后的路径会把"不可达"转化为真实几何穿透，与 API 校验引擎的"接触距离超阈值"判定互补。
