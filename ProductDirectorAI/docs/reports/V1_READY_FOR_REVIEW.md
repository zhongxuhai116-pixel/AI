## 4. 明确不在 V1 范围（避免误解）

1. **外观与材质**：官方 STEP 不含外观，转出的 GLB 材质数为 0，渲染为默认白色；图片/视频的材质与颜色保真属于 **V3**。
2. **多 Owner / 多租户**：当前是私有单 Owner 部署，没有账号体系。
3. **前端未暴露的编辑项**：相机轨迹、产品位姿、场景布光目前通过 API 与合同驱动，界面只有分镜字段与裁切锚点。
4. **未做**：真实用户并发压测、跨机（物理分离）远程 Worker 实测、HTTPS 反向代理与公网暴露、成本/稳定性三次对照。
5. **云 SSH 访问**：依赖云防火墙白名单 + 专用密钥；轮换凭据时需要重新授权。
