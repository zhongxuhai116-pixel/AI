## 2. 真机校准（云端 Blender 5.2.1，540×960，72 帧，3 镜头 ×24）

- **校准发现**：CC0 Camera_01 归一化后世界包围盒 x[-0.59,0.59] y[-0.725,0.725] z[0,0.43]（镜头轴沿 Y）。默认机位按 1.45m 高产品设计，该产品只占画面约 5%。校准后按产品实际尺寸给出三镜头机位（dolly 2.2→1.5m、side ±0.35m、orbit r1.8m，target (0,0,0.21)），经计划合同 `camera_path/position_m` 传递——**不修改默认机位，V1/V2 行为不变**。
- 校准后取景：CC0 掩码覆盖 12.5–25.1%（均值 18.3%）、包围盒高 22–30% / 宽 89–97%；官方模型默认机位覆盖 8.2–22.1%（均值 14.8%）、包围盒高 39% / 宽 71%。
- 两类产品映射（§9.11）：**官方 STEP→GLB** = 刚性不透明几何类；**CC0 Camera_01** = 带纹理 + 细杆/孔洞结构类。**透明/强反射材质显式不支持**（§9.11 允许明确排除），暂不计入已支持类别。
