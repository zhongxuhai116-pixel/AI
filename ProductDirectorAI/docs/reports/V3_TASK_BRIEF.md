## 1. V3 的目标（规格原文）

建立可验证的 **Strict Fidelity**：产品主体来自已批准 3D 产品版本和可追溯 Blender 渲染，AI 只处理允许区域；每条成果可查看产品来源、保护区域、合成方式和质量报告。

关键限定：Strict 保证的是"本系统遵守已批准资产的保护合同"，**不保证输入资产等同于现实实物**。对重建资产必须分开显示"几何/外观已核实范围"与"本次合成是否保持已核实资产"。

## 3. 明确不做（本期不扩大能力）

- CONTROLLED / CREATIVE 不做：沿用 V2 的预览标识与显式入口，不扩大模型能力。
- 不自动修复模型缺陷：审核不通过时允许返回外部建模工具修复后重新导入新版本。
- 不用生成图把未核实区域变成已核实事实：单图重建的未观测面必须保持 `unverified`。

## 4. 已知风险与不确定点

| 风险 | 说明 |
| --- | --- |
| 通道导出工程量 | 现有渲染脚本只出 PNG 帧；多通道需要配置多个 pass 并分别落盘，还要保证编码与色彩管理不串味 |
| 合成数学 | 必须在线性空间做，显示变换要记入 Manifest；这是"看起来差不多但不可复现"的典型坑 |
| 官方模型无材质 | 官方 STEP 转出的 GLB 为 0 材质。Strict 合成可验证几何/轮廓/尺寸，但 **Logo 保护需要带纹理或材质的模型** |
| 单卡产能 | V2 实测产品替换视频约 510 秒/条；多通道渲染会增加耗时，需重新实测 |

## 5. 需要决定的三件事

1. V1 / V2 是否 ACCEPTED（决定能否按规划顺序进入 V3）。
2. 是否提供**带材质的模型或纹理**：V3-07 要求"Logo 缺失能被检出"，而当前官方 GLB 无材质，Logo 保护无法用现有资产验证。
3. V3 是否按上表开工，或先做前几项（例如先打通 V3-01/02 多通道，再决定合成与 QA 的深度）。
