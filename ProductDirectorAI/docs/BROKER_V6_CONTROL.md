## 本阶段下一批建议（Q01–Q06 独立复验后派工）

1. 固定 Strict 运行快照：产品版本、审核版本、策略版本、允许视角、各输入层引用/哈希及输出规格。现有审核记录可更新产品版本的投影字段，运行必须引用冻结审核快照，不能依赖可变最新值。
2. 补真实分层合成：保留可信连续 Alpha 与颜色约定，生成掩码外扩不应简单变成产品不透明外扩；背景替换、阴影、反射、人物遮挡的输入合同与支持边界需分开记录。技术语义实施时核对当前 Blender 官方资料与现场版本。
3. QA结果与Run状态联动、完整人工审核及批准hash绑定、修改失效；失败输入或QA失败不得走到成功/发布。
4. 真实素材、故障注入、UI、旧版回归及性能验收；不足项继续本阶段，不越级开后续业务。
